## Technical Decisions

1. **No Redux:** React hooks + useState for state management (keep monolithic App.tsx architecture)
2. **CSS Modules:** Scoped component styles (WireCard.module.css, etc.)
3. **GPU Acceleration:** All animations use transform + opacity (no layout properties)
4. **Responsive Breakpoints:** 3-tier strategy (1920×1080 desktop, 768×1024 tablet, 375×667 mobile)
5. **Animation Framework:** useAnimationFrame hook + @keyframes utilities for 60fps consistency
6. **Accessibility First:** Semantic HTML, aria-labels, focus ring (2px solid, ≥3:1 contrast)
7. **Theme System:** CSS variables + @media prefers-color-scheme (defer theme switcher UI to post-Phase 3)
